# Сайт «Мои авторские работы»

Готовый проект для GitHub Pages для репозитория `ekaterinaarseneva532-maker-.github.io`.

## Что есть
- главная страница;
- галерея работ;
- отдельная страница каждой работы;
- фотографии через `assets/uploads`;
- поля: название, категория, размер, материалы, техника, описание;
- контакты и ссылки на VK, Telegram, Instagram, YouTube и личный сайт;
- базовая SEO-разметка и sitemap;
- страница `/admin/` со ссылкой на Pages CMS.

## Важно
GitHub Pages публикует сайт из репозитория. Pages CMS является отдельной панелью редактирования, которая записывает изменения непосредственно в файлы GitHub.
